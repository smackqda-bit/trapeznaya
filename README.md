# Трапезная Купца — сайт

Новогодняя версия сайта столовой «Трапезная Купца» (Псков) в стиле премиального минимализма.
Next.js 16 (App Router) + Tailwind CSS 4 + TypeScript.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # продакшн-сборка
npm start
```

## Где что менять

- **Тексты, цены, контакты, новости, отзывы, галерея** — `src/content.ts`.
- **Фото** — положите файлы в `public/photos/` и укажите путь в поле `image`
  (например, у слайда галереи: `image: "/photos/hall.jpg"`). Пока фото нет, показывается заглушка.
- **Цвета и шрифты** — блок `@theme` в `src/app/globals.css`.
- **Разделы страницы** — `src/components/`, порядок разделов — `src/app/page.tsx`.

## Разделы

Шапка · Главный экран (снег) · Новости и акции (корпоративы 3 500 ₽, салаты на заказ, приз за подписку ВК) ·
О нас · Галерея (листание стрелками, свайпом, автолистание) · Всё в одном месте · Обеды с формой заявки ·
Доставка · Отзывы · Контакты.

## Заметки

- Форма заявки открывает письмо на `TrapeZnKup1q@yandex.ru` в почте посетителя.
  Для приёма заявок на сервере (Telegram-бот, CRM) замените обработчик в `src/components/LeadForm.tsx`.
- Шрифты Cormorant и Manrope подключены локально через `@fontsource`, запросов к Google нет.
- Деплой: проще всего Vercel — импортируйте репозиторий, настройки по умолчанию.
